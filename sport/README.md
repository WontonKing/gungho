# 動得剛剛好｜個人體適能規劃

依身體狀況、工作性質、目標及可用時間，產生一般體適能教育課表。以 40 歲以上成人為重點，輸入支援 18–100 歲。實際執行以專業教練指導、醫師及物理治療師評估為準。

## 使用

1. 開啟 `index.html`（下載包的根目錄），或將檔案部署到靜態網站。
2. 完成健康安全篩檢、工作與目標、可用星期與時間。
3. 閱讀聲明後產生課表。若需專業評估，頁面會暫停排課。
4. 選擇主要有氧及可輪替項目、器材與「輪替組合／熟悉優先」，再產生課表。
5. 選擇週次，查看動作、時間分配、目標差距與工作間歇建議。展開「選擇替代動作」可替換同類動作，課表與匯出同步更新。
6. 用「列印／另存 PDF」輸出本週課表；用 CSV 輸出本週或完整計畫，Excel 可直接開啟。
7. 匯出 `.ics`，再到自己的 Google／Apple／Outlook 行事曆確認匯入。預設只匯出目前一週。

課表以輸入日期為第 1 週起點，每週為連續 7 天，不強制從週一開始。排課依實際星期比對，不會錯把第一天當週一。開始時間及行事曆匯出以台灣 UTC+8 為準，其他地區請在匯入後調整。

## 運動項目擴充

內建 78 項：15 項有氧與休閒、37 項全身肌力、12 項活動度與柔軟度、10 項平衡與協調、4 項日常功能。運動庫可依類別、關鍵字與目前器材／條件篩選。

新增舞蹈、水中有氧、橢圓機、健走杖、走跑交替、健行、划船機、桌球、羽球，及徒手、阻力帶、啞鈴、器械的肌力動作。有的項目限已有規律習慣者或需專業確認，並非全部適合每個人。瑜伽、皮拉提斯、太極的短活動序列不等同完整課程。

預設輪替依星期與週次安排同類動作，時間與安全限制不變；「熟悉優先」使用固定組合。CSV／ICS 會包含實際選取與替換的動作、口訣及劑量。手動替換不會改變課次總時間，仍需教練確認新動作品質。重新產生課表會重建動作組合；目前不保存手動替換到下次開啟。

## 自行部署

下載包根目錄含 `index.html`、`styles.css`、`exercise-library.js`、`model.js`、`app.js`、`.nojekyll`。不需要資料庫、API 金鑰、套件安裝或後端。

- GitHub Pages：將下載包內容上傳儲存庫根目錄，在 Settings → Pages 設定分支及根目錄，儲存後使用 GitHub 顯示的網址。
- 一般主機：將上述六個檔案放在同一個網站資料夾，以 HTTPS 提供 `index.html`。
- 可部署在子目錄；CSS／JS 使用相對路徑。
- 本專案原始碼的 `dist/` 就是下載包根目錄所對應的網站檔案。

本包沒有帳號密碼或服務端資料庫。若部署為公開靜態網站，任何人都可開啟頁面；每位使用者的輸入仍在自己的瀏覽器內計算。私人預覽的登入限制由託管平台提供，下載包不含該平台登入機制。

## 行事曆

行事曆是一次性檔案匯入，不是帳戶直接連線，也不會自動同步；不用提供登入密碼。未來週次都是待專業人員確認的草案。

- [Google 匯入說明](https://support.google.com/calendar/answer/37118)
- [Apple Mac 匯入說明](https://support.apple.com/guide/calendar/icl1023/mac)
- [Outlook 匯入說明](https://support.microsoft.com/en-us/outlook/import-or-subscribe-to-a-calendar-in-outlook-com-or-outlook-on-the-web)

建議使用獨立「運動草案」行事曆。重新匯入前整理舊事件，避免重複。提醒是否啟用、重複事件是否合併及手機支援，依行事曆服務商規範而異。

## 隱私與模型限制

健康資料在瀏覽器端計算，無分析追蹤、無健康資料 API。預設不儲存；使用者按「記住輸入」才會存入本機 `localStorage`。按「清除已存資料」可刪除持久輸入與目前畫面資料。使用共用裝置時請勿儲存。

CSV／ICS 不含勾選的診斷項目、身高或體重，仍包含依狀況調整過的運動內容。列印課表包含本次注意事項，可間接顯示健康狀況，請自行保管。

一般活動量標準與工具設計假設請參閱 `MODEL.md`。本模型未經臨床或成效驗證，不可當作正式運動處方、復健醫囑或醫療器材。沒有減重、增肌、改善疾病的成效保證。

## 驗證
