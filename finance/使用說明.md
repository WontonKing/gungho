# 退休預備理財規劃模擬器

## 直接試用
下載「退休預備理財規劃模擬器.html」，在 Windows 或 Mac 以 Edge、Chrome、Safari 開啟，不需安裝。
手機請使用已部署的網頁；部分手機檔案檢視器不執行 HTML 內的 JavaScript。

## 操作
1. 調整目前年齡、退休年齡與規劃終點。
2. 填入實領收入、支出、可投入金額與退休生活費。
3. 展開資產配置與年金欄位，填入實際資產及官方預估給付。
4. 查看資金目標、缺口、額外月投入、資產曲線、情境比較。
5. 可切換今天購買力，儲存／匯出 JSON 方案或下載年度 CSV。

所有預設數字都是示範。金額以新臺幣計算；資產以萬元輸入，其餘多為元。退休後生活費、醫療和長照不可重複填入。生活費填今天金額，年金填開始領取當年的金額。

勞退一次領和月領擇一，避免重複計入。自住房和出租屋價值僅作盤點，不計可提領資產；租金請填淨收入。投資配息已含於總報酬，不宜再作額外退休收入。

## 網頁部署
解壓縮後將 index.html、styles.css、model.js、app.js、.nojekyll 同時放入網站同一資料夾即可。GitHub Pages 可直接使用根目錄部署。此下載包未包含任何使用者輸入或已儲存的方案。

## 計算與限制
月度現金流與反向折現，支應至規劃終點，額外儲蓄依月度複利倒算。報酬為固定名目年率並扣年費用；非隨機市場模擬，沒有成功率。生活現金預備金已屬退休資產，不再次加入目標。

在職收支為負時不自動從資產扣除赤字；指定投入超過可用結餘時會提示。60 歲前退休的勞退一次領橋接、政策變更、稅務、交易成本、個別資產波動未建模。

主要結果以完整月度現金流計算，提領率法只作首年缺口的粗略比較。列印前可自行展開年度明細。

## 個資與用途
所有輸入在瀏覽器內計算，不上傳伺服器。按儲存後才存入瀏覽器本機儲存；共用電腦可清除。匯出的 JSON 及 CSV 包含個人財務資料，請自行保管。

本工具僅供學習與參考，不構成個人理財、投資、投保或稅務建議。給付金額及資格以主管機關核定為準。制度文字查核日：2026-10-11。
