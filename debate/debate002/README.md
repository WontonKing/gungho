# 健保費率辯論｜雙 AI 接力辯論全場回顧（debate-002）

出品：共好公共政策AI審議室

單頁靜態網站，無需建置，可直接部署到 GitHub Pages。

## 部署步驟

1. 在 GitHub 新建一個 repository（例如 `debate-002`）。
2. 把本資料夾的 `index.html`、`.nojekyll`、`README.md` 上傳到 repository 根目錄。
3. 進入 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 約一兩分鐘後，網站會出現在 `https://<你的帳號>.github.io/debate-002/`。

## 檔案說明

- `index.html`：完整網頁（樣式與程式都在同一檔）。字型透過 Google Fonts 載入，離線時會自動改用系統字型。
- `.nojekyll`：讓 GitHub Pages 直接提供靜態檔案，不經 Jekyll 處理。
