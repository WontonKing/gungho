單頁靜態網站，無需建置，可直接部署到 GitHub Pages。

## 部署步驟
1. 在 GitHub 新建一個 repository（例如 `debate-003`）。
2. 把本資料夾的 `index.html`、`.nojekyll`、`README.md` 上傳到 repository 根目錄。
3. 進入 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 約一兩分鐘後，網站會出現在 `https://<你的帳號>.github.io/debate-003/`。
