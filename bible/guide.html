一年讀經 · 網頁版

使用說明

每天大約 20–30 分鐘：讀三段經文，寫幾句筆記。360 天讀完整本聖經。手機、平板、電腦都能用，不需要帳號。

加到主畫面（像 App 一樣使用）

第一次打開網址後，把它加到主畫面，以後點圖示就能直接開啟，沒有網路也能讀經、寫筆記。

裝置做法
iPhone / iPad用 Safari 打開 → 按下方 分享 圖示 → 加入主畫面 → 新增
Android用 Chrome 打開 → 右上角 ⋮ → 加到主畫面 或 安裝應用程式
Windows / Mac 電腦用 Chrome 或 Edge 打開 → 網址列右邊的 安裝 圖示（或選單裡的「安裝一年讀經」）
iPhone 上一定要加到主畫面，並且以後都從主畫面的圖示打開。直接在 Safari 分頁裡使用的話，太久沒打開時 Safari 可能會清掉筆記。

每天怎麼用

  1. 打開「一年讀經」，程式會自動跳到今天。
  2. 上方三張卡片是今天的進度：詩歌智慧書、舊約、新約。點一張，下面就顯示那段和合本經文。
  3. 讀完後，在「讀經筆記」寫下觸動你的經文、領受或禱告。打字就會自動儲存。
  4. 勾選 今天的進度讀完了（寫了筆記也算完成）。

第一次使用時，請在 設定與備份 選好「開始日期」，按 儲存開始日期。

用說的寫筆記（語音輸入）

按筆記下方的 語音輸入，第一次會問能不能使用麥克風，按 允許。對著裝置說話，文字會接在游標的位置；說完按 停止語音，筆記一樣會自動儲存。

  • 說「逗號」「句號」「問號」「驚嘆號」會打出標點，說「換行」會換到下一行。每一段話之間會自動加逗號。
  • 語音辨識由瀏覽器提供，需要連上網路。電腦請用 Chrome 或 Edge；Android 用 Chrome；iPhone 用 Safari。
  • 如果沒有看到按鈕或按了不能用，點一下筆記欄，按手機鍵盤上的麥克風鍵直接說話，效果一樣好。

關鍵字查經

按上方 查經（電腦也可以按鍵盤 /），輸入想找的字詞，就會列出整本和合本裡有這些字的經節，關鍵字會用黃色標出來。

  • 多個關鍵字：用空白隔開，例如 信心 盼望，會找出同時有這兩個詞的經節。
  • 直接查章節：輸入 詩 23、羅 8:28、約 3:16-21，書卷可以用簡稱或全名。
  • 縮小範圍：選單可以選舊約、新約、詩歌智慧書、四福音、保羅書信，或任何一卷書；結果上方的書卷小標籤也可以點，只看那一卷。
  • 看整章：點經文出處（例如「約翰福音 3:16」），會打開整章（詩篇是整篇），那一節用金色標出；用 ‹ › 翻章。
  • 讀經第 N 天：跳到這一輪讀經計畫裡讀這節經文的那一天。
  • ＋筆記：把這節經文（含出處）加到目前所看那一天的讀經筆記裡。

讀經提醒

網頁不能自己在背景跳出提醒，所以改用手機或電腦的「行事曆」：

  1. 設定與備份 → 讀經提醒 → 選 每天提醒時間。
  2. 按 加入行事曆提醒，會下載一個「一年讀經提醒.ics」。
  3. 打開這個檔案，選 加入／新增至行事曆。之後每天時間到，行事曆就會提醒你，提醒裡有這個網頁的連結。
想要早晚各一次，就換個時間再按一次。不需要了，到行事曆裡刪除「一年讀經」這個重複事件即可。也可以直接用手機的「時鐘 → 鬧鐘」設定。

切換日期、補進度

  • ‹ 前一天／後一天 ›，電腦也可以用鍵盤 ← →。
  • 今天：回到今天的進度。
  • 月份下拉選單跳到某個月的第一天；點小圓點跳到那一天。
  • 落後了沒關係，回到沒讀的那天補讀、補寫筆記即可。

想改開始日期：設定與備份 → 開始日期 → 儲存開始日期。筆記跟著「第幾天」走，改日期不會弄亂筆記。

進度與完成

每一天只要寫了筆記或勾選讀完了，就算完成。月份列右邊和 設定與備份 裡的進度條會顯示「本輪已完成 x / 360 天」。

下一輪：重新調整讀經組合

360 天全部完成時，畫面上方會出現「恭喜！」，這時可以按 安排下一輪：程式會把詩歌智慧書、舊約、新約的書卷重新排序，不喜歡就按 換一個組合，選好開始日期後按 確認，開始新一輪。

一旦確認就鎖定。新的一輪要等 360 天全部完成，才能再調整組合。以前各輪的筆記都會保留。

在多台裝置使用

筆記存在每台裝置自己的瀏覽器裡，手機和電腦不會自動同步。要換到另一台裝置接著寫：

  1. 在原來的裝置：設定與備份 → 下載備份檔（手機上可以按 分享備份檔，存到 Google 雲端硬碟、iCloud 雲碟，或用 LINE 傳給自己）。
  2. 在另一台裝置打開同一個網址：設定與備份 → 還原備份檔，選剛才那個 .json 檔。

還原是「合併」：同一天兩邊都有筆記時，保留比較新的那一份，不會把現有筆記整個蓋掉。建議固定一台裝置寫筆記，其他裝置主要用來讀經和查經，會最簡單。

之前用「離線安裝版」寫的筆記，也可以用它的備份檔直接還原到網頁版。

備份與還原

電腦：自動備份到資料夾

在電腦上用 Chrome 或 Edge 開啟時，設定與備份 → 選擇備份資料夾，之後每次寫筆記都會自動存：讀經備份_最新.json，以及每天一份 讀經備份_日期.json。選 Google 雲端硬碟（電腦版）裡的資料夾，就多了一份雲端保險。每次重新開啟時，若上方出現「自動備份暫停中」，按一下 允許自動備份。

手機、Safari、Firefox：手動備份

這些瀏覽器不能寫入資料夾，請每週按一次 下載備份檔 或 分享備份檔，存到雲端。

匯出筆記

匯出筆記（Excel 可開的 CSV） 會下載一份表格：輪次、天數、日期、經文範圍、是否讀完、筆記、最後更新時間，用 Excel 或 Google 試算表都能打開。

常見問題

沒有網路可以用嗎？
可以。只要用網路打開過一次（最好加到主畫面），之後沒網路也能讀經、查經、寫筆記。
筆記不見了？
筆記存在瀏覽器裡。換了瀏覽器、清除了瀏覽器資料、或在無痕模式使用，都會看不到。請從主畫面的圖示打開；真的不見了，用備份檔「還原備份檔」找回來。
別人看得到我的筆記嗎？
看不到。網頁只提供經文和程式，筆記只存在你自己的裝置上，不會上傳到任何地方。
可以給朋友用嗎？
可以，把網址傳給對方就好。每個人的筆記各自存在自己的裝置。
字太小？
手機用兩指放大；電腦按 Ctrl + +（Mac 用 ⌘ + +）。
